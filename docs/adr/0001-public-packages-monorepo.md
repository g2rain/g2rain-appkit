# ADR-0001：独立应用仓库与公共包 Monorepo

- 状态：已接受
- 日期：2026-09-09

## 背景

多个前端应用由独立 Git 仓库维护，共享代码依靠复制传播，导致缺陷修复、主题升级和新应用初始化难以保持一致。

## 决策

保留业务应用独立仓库；`g2rain-appkit` 内部使用 npm workspaces 管理 `theme`、`ui`、`http` 和 `runtime` 等可独立发布的包。

## 结果

- 公共能力具有唯一事实来源和明确版本。
- 应用可以独立决定升级时间。
- 公共包可以在同一仓库联调和统一验证。
- 需要维护发布顺序、跨仓库兼容性和真实应用制品验证。
